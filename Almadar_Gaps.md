- **G-ORBITAL-CORE-002** — `EmbeddedKernel::frame` costs about 0.11 ms per ticking trait. On the iOS simulator (iPhone 17 Pro, release C-ABI lib from `make ios-lib`), a frame with 100 ticking traits takes p50 11.4 ms and with 1 000 takes p50 557 ms / p95 752 ms, so every one of 600 frames misses the 16.7 ms budget and the R1-device frame gate (2 ms) by about 280×. Dispatch is fine (p50 0.15 ms over 10^4 events). Suspects: the frame path in `runtime/kernel.rs` and `effects/executor.rs` (per-trait entity layering, per-tick response building, render-store work per tick). Fix: profile one frame (allocation count + time per stage, like `tests/dispatch_alloc_count.rs`), then cut per-trait work so cost grows with traits that actually change. `orbital-core` [architectural] — evidence: `@almadar-io/parity` device rows (`frame-60hz-100`, `frame-60hz-1000`), `orbital-shell-ios/tests/device-bench/`; prevention rung: none of the language rungs (performance), gated by the device frame row.
- **Close by deleting.** Remove the entry in the same commit as the fix.

- **G-ORBITAL-CORE-038** — The dispatch lane (`crates/runtime/src/kernel/lane.rs`) still lets an UNTOKENED call re-enter when it runs on the thread the RUNNING holder occupies. The parked refusal and the FIFO wait are keyed on an explicit `LaneTurn` (R-b1, 2026-10-21), and the kernel's own sub-dispatches carry the turn, but `orbital-server`'s `program/dispatch` substrate host (`ServerSubstrate::run`, `runtime.rs`) answers the ask in place with `dispatch_continuing`, and `SubstrateHandler::run(op, args)` hands it no turn to carry. It is sound (a running holder occupies its thread synchronously), but it is implicit. Fix: pass the asking dispatch's `LaneTurn` to the substrate/service host (`SubstrateHandler::run` or `ServiceCaller`), have `ServerSubstrate` call `dispatch_in_turn`, then delete the `in_place` clause from `DispatchLane::enter`. `orbital-core-runtime` + `orbital-server` [architectural] — prevention rung: none of the language rungs (host concurrency), gated by the `tests/cross_trait_dispatch.rs` lane pins and `orbital-server` `go_as` program/dispatch tests.
