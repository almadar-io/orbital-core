- **G-ORBITAL-CORE-050** — The static `os/write-file` grant requirement (`crates/base/src/host/os_grants.rs` ~1570) asks only `write`, but the host demands `create` when the target does not exist yet (`os_host/fs.rs` `write_target`), and the op's own docstring says "grant fs: write, create"; so `ORB_OS_GRANT_UNUSED` warns on a `create` grant a program needs (std-orb-signatures `--out`: 2 warnings it cannot clear without breaking a fresh output file).
